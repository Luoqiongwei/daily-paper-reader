## 摘要
检测和清理表格数据中的错误是数据密集型软件应用的前提。机器学习与数据库管理系统交叉领域的最新研究凸显了统计学习算法在错误检测和清理方面的潜力。本文在统一演示器中结合了我们近期在基于ML的数据清洗和错误模型方面的工作。该Web应用允许用户上传表格数据，用真实的数据依赖错误扰动数据，并使用现代ML方法清理和理解数据中的错误机制。我们的演示器有助于弥合表格数据错误模型和数据清洗算法领域理论进展与直观实践见解之间的差距。演示器可在 https://cured.demo.calgo-lab.de/ 获取。

## Abstract
Detecting and cleaning errors in tabular data is a prerequisite for data intense software applications. Recent research at the intersection of Machine Learning (ML) and Database Management Systems (DBMS) highlights the potential of statistical learning algorithms for error detection and cleaning. This paper combines our recent work on ML-based data cleaning and error models in a unified demonstrator. The web application allows users to upload tabular data, perturb the data with realistic data dependent errors and use modern ML methods to clean and understand error mechanisms in data. Our demonstrator helps to bridge the gap between theoretical advancements and intuitive practical insights in the context of error models and data cleaning algorithms for tabular data. The demonstrator is available at https://cured.demo.calgo-lab.de/

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：构建一个三阶段Web演示器（错误创建 → 错误修复 → 错误理解），支撑用户上传数据、注入预定义的现实依赖错误、应用ML方法清洗并分析错误机制。
- **关键技术细节**：
  - **错误生成（tab-err库，见[Jung et al., 2025b]）**：
    - 参数化：错误类型（如数值型Outlier/WrongUnit/AddDelta，类别型Typo/Replace/Extraneous）、错误机制、错误率。
    - 错误机制分类（基于Rubin缺失数据理论的推广）：
      - ECAR（完全随机错误）：独立于数据。
      - EAR（随机错误）：依赖于其他列数据。
      - ENAR（非随机错误）：依赖于同一列数据。
    - 错误率 = 错误单元格占总单元格比例。
  - **错误修复（保形数据清洗CDC，见[Jäger and Biessmann, 2024]）**：
    - 对每列训练一个ML模型（以其他列为特征预测该列），形成d个imputer。
    - 利用保形预测（conformal prediction）为每个单元格生成预测集C(X_test)，若原值不在预测集中则标记为错误。
    - 将错误单元格置为NaN，再用ML点预测填充（转化为缺失值插补问题）。
    - 用户可指定置信水平（默认0.999）和下游任务类型。
  - **错误理解（MechDetect，见[Jung et al., 2025a]）**：
    - 通过比较不同ML模型在预测误差掩码（error mask）上的性能，推断误差机制（ECAR/EAR/ENAR）。
    - 输出预测的误差机制及p值，帮助用户理解误差产生原因。

- **算法流程（文字说明）**：
  1. 加载数据（用户上传或预加载核电站数据集子集，限制<10列/<10000行，需含target列，80%训练，20%用于错误生成、清洗和评估）。
  2. 用户点击“Inject Errors”配置错误类型、机制、率，生成带错误表格（错误标红）。
  3. 用户点击“Run Conformal Cleaning”，指定任务类型与置信水平，CDC检测并修复错误。
  4. 用户点击“MechDetect”，系统报告预测的误差机制与p值。

## 6. 论文的主要结论与发现
- CURED演示器成功将三项研究成果整合为易于使用的Web工具，用户可交互体验从错误注入、清洗到机制分析的全流程。
- CDC在ECAR/EAR/ENAR下均有可接受的TPR（~0.65）和极低FPR（~0.007），并能带来下游性能提升（DSI 0.007~0.035）。
- MechDetect在数值型数据下对ECAR、EAR、ENAR的检测准确率分别为94.2%、99.0%、73.3%；在类别型数据下分别为92.95%、99.84%、70.79%。EAR检测准确率最高，ENAR检测难度最大（准确率仅~70%）。
- 演示器有助于培养用户对表格数据错误模型和清洗算法的直觉。
