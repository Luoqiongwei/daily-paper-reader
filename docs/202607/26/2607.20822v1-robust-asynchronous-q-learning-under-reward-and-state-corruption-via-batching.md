## 摘要
受恶劣环境中强化学习的启发，我们考虑在对抗性破坏反馈下学习最优策略的问题。具体而言，在每个时间步，对手可以根据Huber污染模型扰动学习者的奖励和状态观测。为了防御此类数据污染，我们提出了{\texttt{BR-Async-Q}}：一种新颖的、基于回合的鲁棒\(Q\)-学习算法，其核心思想包括：(i) 将在线数据流划分为批次以减少方差，以及(ii) 利用这些批次数据构建Bellman最优算子的鲁棒估计。我们证明了{\texttt{BR-Async-Q}}的一个高概率\(\ell_\infty\)误差界，该误差界与普通\(Q\)-学习相当，只多了一个随污染样本比例变化的小加性项。据我们所知，这为同时面临奖励和状态污染的异步\(Q\)-学习提供了首个鲁棒性保证。此外，当只有奖励被污染时，我们算法误差界对污染比例的依赖达到了极小极大最优。

## Abstract
Motivated by reinforcement learning in harsh environments, we consider the problem of learning an optimal policy subject to adversarially corrupted feedback. Specifically, at each time-step, an adversary can perturb both the reward and state observations of the learner following the Huber contamination model. To defend against such data corruption, we propose {\texttt{BR-Async-Q}}: a novel, epoch-based, robust \(Q\)-learning algorithm built upon two key ideas: (i) partitioning the online data stream into batches to reduce variance, and (ii) constructing robust estimates of the Bellman optimality operator using such batched data. We prove a high-probability $\ell_\infty$ error bound for {\texttt{BR-Async-Q}} that matches that for vanilla \(Q\)-learning, up to a small additive term that scales with the fraction of corrupted samples. To our knowledge, this provides the first robustness guarantee for asynchronous \(Q\)-learning subject to both reward and state corruption. Furthermore, when only rewards are corrupted, the dependence of our algorithm's bound on the corruption fraction is minimax optimal.

#### 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：放弃传统的每步更新方式，转而采用**回合制（epoch-based）批处理**策略。将在线数据流分为多个等长区间（epoch），在每个epoch内收集足够多的样本，然后利用这些样本构建**鲁棒的Bellman最优算子估计**，仅在epoch结束时更新一次Q表。通过增大批大小（epoch长度）来降低估计方差，从而缩小误差界并消除对最小访问概率的欠佳依赖。
- **关键技术细节**：
  1. **数据收集与划分**：每个epoch \(k\) 内，为每个状态-动作对 \((s,a)\) 维护两个数据集：
     - \(D_k(s,a)\)：收集污染的即时奖励 \(\tilde{r}_t\)。
     - \(Y_k(s,a)\)：收集基于当前Q表 \(Q_k\) 和污染下一状态 \(\tilde{s}_{t+1}\) 计算的bootstrapped值 \(\max_{a'} Q_k(\tilde{s}_{t+1}, a')\)。
  2. **鲁棒均值估计**：使用两种截尾均值估计器：
     - 对奖励使用 `TRIM_H`（适用于未知方差、重尾分布），得到 \(\hat{R}_k(s,a)\)，误差界为 \(O(\sqrt{\varepsilon_R} + 1/\sqrt{N})\)。
     - 对bootstrapped值使用 `TRIM_B`（利用已知界 \([-B,B]\) 进行更紧的截断），得到 \(\hat{\mu}_k(s,a)\)，误差界为 \(O(\varepsilon_Y + 1/\sqrt{N})\)。
  3. **保证足够访问量**：选取epoch长度 \(H = \Omega((1/\lambda_{\min})\log(T|S||A|/\delta))\)，确保高概率下每个状态-动作对在每个epoch内至少被访问 \(0.5\lambda_{\min}H\) 次（引理2）。
  4. **裁剪与更新**：定义裁剪阈值 \(G_k = O(\tilde{\sigma}(\sqrt{\varepsilon_R} + \sqrt{\log(1/\delta)/(\lambda_{\min}H)}))\)，对奖励估计进行裁剪，然后构造经验Bellman算子 \(\hat{T}_k Q_k(s,a) = \text{clip}_{[-G_k,G_k]}(\hat{R}_k(s,a)) + \gamma \hat{\mu}_k(s,a)\)。最后使用固定步长 \(\alpha\) 进行Q表更新：\(Q_{k+1} = (1-\alpha)Q_k + \alpha \hat{T}_k Q_k\)。
- **算法流程**（文字说明）：见Algorithm 2（BR-Async-Q）。输入：步长、污染率、置信度、总步数T、epoch长度H、epoch数K。初始化Q=0。对每个epoch k：
  - 初始化空数据集。
  - 在epoch内逐步收集观测，将 \((\tilde{r}_t, \max_a Q_k(\tilde{s}_{t+1}, a))\) 存入对应 \((s_t,a_t)\) 的数据集。
  - epoch结束后，对每个 \((s,a)\) 调用 `TRIM_H` 和 `TRIM_B` 得到鲁棒估计。
  - 计算经验Bellman算子并裁剪。
  - 执行更新 \(Q_{k+1} = (1-\alpha)Q_k + \alpha \hat{T}_k Q_k\)。
