## 摘要
可验证奖励强化学习（RLVR）已成为提升大语言模型推理能力的有效框架，其中GRPO等方法是最成功的实例之一。然而，GRPO依赖于重复生成长思维链展开，训练时间随展开次数增加，且大部分展开信息量不足，导致计算成本高且不稳定。为缓解这一问题，现有方法要么生成更大规模的展开池并筛选信息量最大的提示，要么在训练后期利用历史信号进行筛选。这些策略虽能带来适度的性能提升，但会拖慢整体过程。为此，我们提出了一种基于方差的在线展开分配方法（VIGOR），该方法并非为每个样本分配固定的展开预算，而是从批次中所有样本的少量展开开始，迭代地将额外展开分配给组奖励方差最高的样本，直至达到固定的总展开预算。理论上，我们证明在RLVR下，奖励方差控制着梯度幅度，并推导出VIGOR相对于GRPO的闭式加速比，该加速比在帕累托分布的奖励方差下随优化轮次增长。在数学推理和编程任务上的实验表明，VIGOR在数学任务上达到目标精度所需的展开次数最多减少2.3倍，在编程任务上以1.49倍更少的展开达到GRPO的最终完整通过率，并将编程平均测试通过率提高了3.4个百分点。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has emerged as a highly effective framework for improving LLM reasoning, with methods such as GRPO among its most successful instantiations. However, GRPO relies on repeated generation of long chain-of-thought rollouts. Training time scales with the number of rollouts, a large fraction of which are uninformative. Thus, GRPO is computationally expensive and unstable. To mitigate this, existing approaches either generate a larger pool of rollouts and filter the most informative prompts, or leverage historical signals for filtering at later stages of training. These strategies offer modest performance gains, but slow down the overall process. To address this, we propose VarIance Guided Online Rollout allocation (VIGOR) which instead of allocating a fixed rollout budget per example, begins with a small number of rollouts for all examples in a batch and iteratively allocates additional rollouts to those with the highest group reward variance until a fixed total rollout budget is reached. Theoretically, we show that under RLVR, reward variance controls the gradient magnitude, and derive VIGOR's closed-form speedup ratio over GRPO, which grows with refinement rounds under Pareto-distributed reward variance. Experiments on mathematical reasoning and coding tasks show that VIGOR reaches target accuracy with up to 2.3$\times$ fewer rollouts on math, reaches GRPO's final coding full pass rate with 1.49$\times$ fewer rollouts, and improves the coding average test pass rate by 3.4 points.

## 1. 核心问题与整体含义（研究动机和背景）
- **背景**：可验证奖励强化学习（RLVR）已成为提升大语言模型推理能力的关键框架，其中 **Group Relative Policy Optimization（GRPO）** 是最成功的实例之一。GRPO 通过对每个 prompt 采样多个 rollouts（推理轨迹）并基于组内相对奖励更新策略，有效提升了数学、代码等任务上的推理能力。
- **核心问题**：GRPO 需要大量生成 rollouts（尤其是长思维链），训练时间与 rollout 数量成正比，但其中很大一部分 rollouts **信息量不足**（例如组内奖励方差为零，导致零优势、零梯度信号）。这不仅导致训练昂贵且不稳定，而且现有改进方法要么依赖生成更大的 rollout 池再过滤（如 DAPO），要么依赖历史统计进行后期筛选（如 GRESO、DPS），这些方法要么带来额外计算开销，要么增益有限且无法在训练早期（贡献最大的阶段）发挥作用。
- **研究动机**：提出一种**自适应、在线、不修改 GRPO 训练目标**的 rollout 分配策略，聚焦于最有信息量的 prompts，从而在不增加总 rollout 预算的前提下提升训练效率和最终性能。

## 2. 论文提出的方法论
### 2.1 核心思想
- 关键观察1：rollout 生成是 GRPO 训练的主要成本（占训练时间 ≥ 50%）。
- 关键观察2：训练早期（第一个 epoch）贡献了约 80% 的性能提升，因此早期高效利用计算资源至关重要。
- **核心洞察**：在二元奖励设定下，GRPO 梯度幅度由组内奖励标准差 σ 控制（定理1）。因此，高奖励方差的 prompt 带来更大的梯度信号，是更有信息量的样本。
- **方法名称**：**VIGOR（VarIance Guided Online Rollout allocation）**。

### 2.2 关键技术细节
- **流程**：VIGOR 在每个训练步（step）中，对当前 batch 的所有 prompt，**先分配少量初始 rollout（例如 m₀=2）**，然后计算每个 prompt 当前所有 rollout 的奖励方差作为效用分数。接着，保留方差最高的 top-α 比例（例如 α=0.5）的 prompt，对它们**追加 rollout**（每次追加量乘以扩展因子 γ，例如 γ=2），而其他 prompt 不再获得额外 rollout。这个过程迭代 T 轮（例如 T=4），直至消耗完与原始 GRPO 相同的总 rollout 预算。最终所有保留的 rollout 均用于正常的 GRPO 策略更新，不改变训练目标。
- **关键符号**：
  - `m₀`：初始 rollout 预算（每 prompt）
  - `α`：每轮保留的 prompt 比例
  - `γ`：扩展因子（每轮追加预算乘以 γ）
  - `T`：迭代轮数
- **算法流程**（文字描述）：
  1. 采样一个 batch `B`。
  2. 对每个 prompt，初始化空 rollout 集；设置活跃集 `A₁ = B`。
  3. 对 `t = 1..T`：
     - 对活跃集 `A_t` 中的每个 prompt，生成 `m_t` 个 rollout，加入其 rollout 集。
     - 计算每个 prompt 的奖励方差 `u_x`。
     - 若 `t < T`，选择方差最高的 top-α 比例 prompts 形成 `A_{t+1}`，并为其倍增 rollout 预算（`m_{t+1}=γ*m_t`）。
  4. 使用所有保留的 rollout 执行标准的 GRPO 策略更新。

### 2.3 理论基础
- **定理1**：在无 KL 项的二元奖励 GRPO 中，梯度范数 ≤ `Mσ`，其中 σ 是组内奖励标准差，M 是重要性采样梯度上界。因此方差越大，梯度信号越强。
- **定理2**：假设 prompt 级奖励方差的尾部服从 Pareto 分布（形状参数 k>1），VIGOR 相对于 GRPO 的加速比（特征时间尺度比）随迭代轮数 T 指数增长（`τ_GRPO / τ_VIGOR = Θ((α^{-1/k})^{T/3})`）。这意味着方差分布越重尾（即高信息 prompt 越稀有但方差极大），VIGOR 的效率优势越大。
