## 摘要
基于分位数的强化学习通过优化累积回报分布的指定分位数，为风险敏感决策提供了一种可解释的方法。尽管这一思路颇具吸引力，但在点分位数目标下学习仍具挑战性：分位数在回报分布的微小扰动下可能发生突变，而精确的分位数敏感规划需要计算代价高昂的分布式优化。下缓冲分位数通过平均紧邻目标水平下方的相邻分位数来缓解前一个困难，在保留底层点分位数目标的同时提供更平滑的替代目标。然而，基于该原理的现有方法仍为基于模型的方法，并依赖显式回报律规划，限制了其在小规模表格问题之外的适用性。我们提出 Deep-BQRL，一种无模型的分布式强化学习框架，将缓冲分位数学习扩展到神经函数逼近。该方法直接从采样转移中学习条件回报分位数，从所学分位数函数的相关区域构造缓冲动作分数，并利用集成分歧引导探索。一种增强的输入表示使所学策略能够对轨迹信息作出响应，而无需显式重现精确规划所需的分位数-状态递归。在资产出售最优停止问题和湿滑 FrozenLake 上的实验，将 Deep-BQRL 与基于模型的 UCB-BQRL 以及表格型 PPO 和 TRPO 实现进行比较。在资产出售中，Deep-BQRL 在报告的目标水平上比 PPO 和 TRPO 取得更小的平均累积点分位数策略差距，而 UCB-BQRL 保持最小的差距。所学到的停止决策也随目标分位数变化，为该方法的风险敏感行为提供了可解释的展示。

## Abstract
Quantile-based reinforcement learning provides an interpretable approach to risk-sensitive decision-making by optimizing a prescribed quantile of the cumulative-return distribution. Despite this appeal, learning under a point quantile objective is challenging: quantiles can change abruptly under small perturbations of the return distribution, and exact quantile-sensitive planning requires computationally demanding distributional optimization. Lower-buffered quantiles alleviate the former difficulty by averaging neighboring quantiles immediately below the target level, providing a smoother surrogate while preserving the underlying point-quantile objective. Existing methods based on this principle, however, remain model-based and rely on explicit return-law planning, limiting their applicability beyond small tabular problems. We develop Deep-BQRL, a model-free distributional reinforcement-learning framework that extends buffered-quantile learning to neural function approximation. The method learns conditional return quantiles directly from sampled transitions, constructs buffered action scores from the relevant region of the learned quantile function, and uses ensemble disagreement to guide exploration. An augmented input representation allows the learned policy to respond to trajectory information without explicitly reproducing the quantile-state recursion required by exact planning. Experiments on an asset-selling optimal-stopping problem and slippery FrozenLake compare Deep-BQRL with model-based UCB-BQRL and tabular PPO and TRPO implementations. In asset selling, Deep-BQRL attains smaller mean cumulative point-quantile policy gaps than PPO and TRPO at the reported target levels, while UCB-BQRL retains the smallest gaps. The learned stopping decisions also vary with the target quantile, providing an interpretable illustration of the method's risk-sensitive behavior.

## 1. 核心问题与研究动机

- **背景**：强化学习通常最大化期望累积回报，但期望无法刻画"坏结果"的概率；风险敏感 RL 关注回报分布而非仅均值，其中**分位数目标**（最大化回报分布的 τ-分位数 Q_τ(R^π)）具有直观可解释性。
- **核心困难一（统计）**：点分位数对回报分布的微小扰动极其敏感，在有限数据下难以稳定估计。
- **核心困难二（计算）**：精确的分位数规划不同于普通 Bellman 优化——最优决策依赖整条轨迹（通过动态更新的分位数水平体现历史依赖），需要显式的回报分布操纵与分布式优化，一般情形下计算困难。
- **已有缓解方案**：Alipour-Vaezi 等提出的**下缓冲分位数（lower-buffered quantile）**，即对 [τ−β, τ] 区间内的分位数取平均，Q^β_τ(W) = (1/β)∫_{τ−β}^{τ} Q_u(W)du，平滑了目标函数且保留分位数解释（与 Range Value-at-Risk 相关，β→0 时退化为点分位数）。但现有 UCB–BQRL 方法**仍是基于模型的**，依赖显式回报律规划与置信集优化，只能用于小规模表格问题。
- **本文目标**：提出 **DEEP–BQRL**，把缓冲分位数学习推广到**无模型 + 神经函数逼近**的分布式 RL 框架，避免学习转移模型和反复求解精确分位数规划。

## 2. 方法论

### 2.1 问题设定
- 有限时域 MDP：M = (S, A, H, P, r)，策略可依赖观测轨迹，回合总回报 R^π = Σ R_h。目标是 max_π Q_τ(R^π)（实际优化其缓冲版本 Q^β_τ）。

### 2.2 三项核心近似
- **近似 I：增强轨迹表示**。用固定维度的轨迹摘要代替完整历史：定义增强输入 X_h := (h, S_h, C_h)，其中 C_h 为选择动作 A_h 前已累积的奖励。critic 学习的是**剩余回报** Z^π(x, a) 的分布，总回报与 c + Z^π(x, a) 同分布。这样策略可对累积奖励（即历史信息）作出反应，而无需显式复现精确规划中的分位数-状态递归。
- **近似 II：剩余回报的分位数表示**。设定固定分位水平 η_j = (j−1/2)/K（j = 1,…,K），维护 M ≥ 2 个独立初始化的 critic，第 m 个 critic 估计 z_{θ_m,j}(x,a) ≈ Q_{η_j}(Z^π(x,a))，即用分位数回归（QR-DQN 式）从采样转移中学习条件分位数。由于可能出现低分位预测值大于高分位预测值的交叉问题，对 K 个输出**排序**得到 z̃_{θ_m,1} ≤ … ≤ z̃_{θ_m,K}，排序值仅用于决策与训练目标构造；训练时原始输出仍与其固定分位水平 η_j 绑定。
- **近似 III：缓冲策略改进**。理论上应按 Q^β_τ(Z^π(x,a)) 比较动作，但仅有 K 个预测分位点。于是把每个分位水平 η_j 视为覆盖区间 [(j−1)/K, j/K]，用其与 [τ−β, τ] 的重叠长度作为权重：
  - **权重公式**：w_j^{τ,β} = [min(τ, j/K) − max(τ−β, (j−1)/K)]₊
  - **缓冲动作分数**：bB_m(x,a) = (1/β) Σ_j w_j^{τ,β} · z̃_{θ_m,j}(x,a)
  - **集成分数**：μ_B(x,a) = (1/M) Σ_m bB_m(x,a)
  - **策略**：π̂(x) ∈ argmax_a μ_B(x,a)

### 2.3 Critic 学习与探索
- 使用经验回放缓冲区 D，样本形式 (x, a, r, x′, d)；终止或到达时域边界时 d = 1。
- 每个 critic 配有慢更新的**目标网络** z̄_{θ_m}。先用目标 critic 在 x′ 上构造缓冲分数 B_m(x′,a)，选出下一动作 a⁺_m(x′) = argmax_a B_m(x′,a)；再构造目标值 y_{m,i} = r + (1−d)·z̃_{θ_m,i}(x′, a⁺_m(x′))（d = 1 时全部退化为 r）。
- **损失函数**：采用分位数 Huber 损失。Huber 损失 h_κ(δ) 对小残差二次、大残差线性；分位数 Huber 损失 ρ^κ_{η_j}(δ) = |η_j − 1{δ<0}| · h_κ(δ)/κ，权重把预测推向 η_j 分位。critic m 最小化 J_m(θ_m)，即在增强表示上应用的分位数回归分布式 Bellman 损失（对 minibatch、K 个目标分位 i 与 K 个预测分位 j 双重求和）。
- **注意**：τ 与 β 不显式出现在分位数 Huber 损失中，它们通过用于选动作与构造目标的缓冲分数影响训练。
- **目标网络软更新**：θ̄_m ← (1−ζ)θ̄_m + ζθ_m。
- **探索**：用集成分歧 σ_B(x,a) = [ (1/(M−1)) Σ_m (bB_m − μ_B)² ]^{1/2} 作为奖励项，行为策略取 argmax_a {μ_B(X_h,a) + λ_t σ_B(X_h,a)}，其中 λ_t = λ_0/(1 + t/λ_decay)，即在**回报值空间**中引导探索。
- **算法 1 流程概览**：初始化缓冲区、M 个 critic 及其目标网络 → 预计算权重 w_j^{τ,β} → 每回合从 x = (0, s, 0) 开始，逐阶段计算 bB_m、μ_B、σ_B，选带探索项的动作，执行并得到 r、s′，构造 x′ = (h+1, s′, c+r) 并存入缓冲区 → 从缓冲区采样 minibatch，逐 critic 排序目标网络输出、选 a⁺_m、构造 y_{m,i}、最小化 J_m 并软更新目标网络 → 终止时跳出。输出为 π̂。

## 3. 实验设计

- **场景一：资产出售最优停止问题（asset selling）**。

  - 动作 A = {Stop, Continue}：Stop 接受报价得奖励 s/24（归一化到 [0,1]）并结束；Continue 立即奖励 0，并从 {0,…,24} 独立均匀抽取新报价；超时未售出回报为 0。
  - 该环境可用于考察风险偏好对停时决策的影响（低 τ 强调防范低售价，高 τ 强调追求高价）。
  - 每轮 2000 训练回合，3 个独立种子。
- **场景二：湿滑 FrozenLake（4×4）**。

  - 每轮 5000 训练回合。
