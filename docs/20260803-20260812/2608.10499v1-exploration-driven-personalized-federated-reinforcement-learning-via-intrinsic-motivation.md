## 摘要
个性化联邦强化学习（PFRL）采用去中心化的方式存储和访问基于过往经验的信息，同时在每个客户端学习其策略时保持各自数据的私密性。当前许多PFRL方法在很大程度上依赖于利用现有的强化学习奖励信号来为每个客户端推导出最优策略，从而忽视了在非平稳或稀疏奖励环境中的探索。在本工作中，我们引入了一种新的探索驱动框架，即基于内在动机的探索驱动的个性化联邦强化学习（EDPFRL-IM），该框架利用每个客户端内在的好奇心驱动探索来促进本地探索并保护客户端隐私。此外，为了通过探索先前未探索的状态空间来促进策略发现，客户端在其外在奖励上增加了一个内在随机网络蒸馏（RND）信号。另外，服务器无法访问客户端的原始经验或本地梯度估计；相反，服务器发送全局探索先验，并从每个客户端收集最少的新颖性摘要，以实现客户端之间既多样化又协调的探索。在基准环境中的实验表明，我们的框架在策略个性化和样本效率方面优于平均的PFRL基准，尤其是在延迟和稀疏奖励系统中。总体而言，EDPFRL-IM能够在保护客户端隐私的同时，将灵活的探索性学习结构集成到联邦强化学习系统中。

## Abstract
Personalized Federated Reinforcement Learning (PFRL) takes a decentralized approach to storing and accessing information based on past experiences while keeping each client's data private during the learning of each client's policy. Many current methods for PFRL rely heavily on exploiting existing reinforcement learning reward signals to derive an optimal policy for each client, thereby neglecting exploration in non-stationary or sparse-reward environments. In this work, we introduce a new exploration-driven framework, Exploration-Driven Personalized Federated Reinforcement Learning via Intrinsic Motivation (EDPFRL-IM), that leverages an inherent curiosity-driven exploration at each client to promote local exploration and protect client privacy. Furthermore, to facilitate policy discovery via exploration in previously unexplored state spaces, clients add an intrinsic random network distillation (RND) signal to their extrinsic reward. Additionally, the server does not have access to clients' raw experiences or local gradient estimates; instead, the server sends global exploration priors and collects minimal novelty summaries from each client to enable both diverse and coordinated exploration among clients. Experiments in benchmark environments show that our framework outperforms average PFRL benchmarks in policy personalization and sample efficiency, primarily in delayed and sparse reward systems. Overall, EDPFRL-IM enables the integration of a flexible exploratory learning structure into federated reinforcement learning systems while preserving client privacy.

- **研究动机**：虽然内在动机方法（如 RND、ICM、基于计数的探索）在集中式 RL 中已有成效，但尚未在联邦场景中充分研究。本文希望弥补这一空白，在保护隐私的前提下引入“好奇心驱动”的探索机制。
- **整体含义**：提出 **EDPFRL-IM**（Exploration-Driven Personalized Federated Reinforcement Learning via Intrinsic Motivation）框架，将内在动机与联邦个性化学习结合，既提升探索效率，又保持客户端数据隐私，从而改善策略个性化和样本效率。

### 2. 方法论：核心思想、关键技术细节、公式与算法流程

- **核心思想**：
  - 每个客户端利用 RND（Random Network Distillation）产生内在好奇心奖励，鼓励访问新颖状态。
  - 服务端不接触客户端原始经验或梯度，只收集压缩的“探索摘要”，聚合出全局新颖性先验，并广播回客户端，实现**协调探索**同时保护隐私。
- **问题形式化**：
  - 设有 N 个客户端，每个客户端 i 有一个本地 MDP \( \mathcal{M}_i = (S_i, A, P_i, R_i, \gamma) \)，其中状态空间和奖励是客户端特定的，动作空间和折扣因子共享。
  - 客户端学习个性化策略 \( \pi_i(a|s) \) 以最大化期望回报：\( J_i(\pi_i) = E_{\pi_i}[\sum_t \gamma^t r_{i,t}] \)。
- **内在奖励（RND）**：
  - 每个客户端维护固定随机目标网络 \( f_{tgt} \) 和可训练预测网络 \( f_{pred} \)。
  - 内在奖励为对下一状态的预测误差：\( r^{\text{int}}_t = \|f_{tgt}(s_{t+1}) - f_{pred}(s_{t+1})\|_2^2 \)。
  - 总奖励：\( r^{\text{total}}_t = r^{\text{ext}}_t + \alpha_i \cdot r^{\text{int}}_t \)，其中 \( \alpha_i \) 控制探索与利用的平衡。
- **联邦协调机制**：
  - 客户端生成压缩探索统计 \( E_i \)，如访问计数、状态嵌入频次直方图、top-k 新颖状态哈希等，发送给服务端。
  - 服务端聚合得到全局探索轮廓：\( G = \text{Aggregate}(\{E_i\}_{i=1}^N) \)，例如 \( v_{\text{global}}[k] = \sum_i v_i[k] \)。
  - 计算全局新颖性先验：\( P_{\text{novel}}(s) = \frac{1}{1 + v_{\text{global}}[\text{cluster}(s)]} \)，并向所有客户端广播。
  - 客户端根据先验调整经验采样概率：\( p_i(s) \propto (1 + \beta \cdot P_{\text{novel}}(s)) \cdot p^{\text{uniform}}_i(s) \)，其中 \( \beta \ge 0 \) 控制全局先验的影响。
- **算法流程（Algorithm 1）**：
  1. 对每个全局轮次 `t = 1..T`，并行执行各客户端；
  2. 客户端交互环境，收集 \( (s_t, a_t, r^{\text{ext}}_t, s_{t+1}) \)，计算内在奖励，更新本地缓冲；
  3. 使用本地 RL 优化器（如 PPO、SAC）更新策略；
  4. 计算并发送探索摘要到服务端；
  5. 服务端聚合摘要生成全局先验并广播；
  6. 客户端根据先验更新采样策略并继续训练。
- **关键设计**：通过压缩摘要和全局先验，实现了跨客户端的“方向性”探索协调，同时避免泄露原始数据和策略参数。
