## 摘要
模型异构联邦学习（MHFL）通过允许每个参与者在共享训练目标下训练个性化模型架构，解决了客户端级别的资源异构问题。一种流行的范式——部分训练（PT）——通过允许每个客户端训练全局模型的一个子网络来实现这一点。然而，现有的PT方法通常依赖于预定义的架构模板或过参数化的超网络，限制了细粒度的个性化，并带来了大量的计算和内存开销。我们提出了FedJigsaw，一种新颖的框架，将模型个性化重塑为动态且去中心化的模型组装问题。每个客户端不是从预定义的超网络中选择子网络，而是通过组装从邻居客户端学习到的可复用模块来构建其模型。在客户端层面，我们引入了AttenAssemble，使每个参与者能够基于本地观察自适应地构建定制模型。为了在通信和隐私约束下支持高效的知识共享，我们设计了SymbioArchitect，一种允许客户端与其拓扑邻居交换细粒度模型模块的机制。为了缓解去中心化模块交换带来的训练不稳定性，我们设计了CoRe-Tune，一种注意力增强的集中训练与去中心化执行策略，指导本地策略以促进隐式协作并稳定训练动态，而不损害数据隐私。大量评估表明，FedJigsaw在相对准确率上比最先进的MHFL基线高出高达13.8%，同时显著缩小了客户端间的性能方差，并且与现有策略驱动方法相比，还大幅降低了决策延迟和峰值内存占用。

## Abstract
Model Heterogeneous Federated Learning (MHFL) addresses client-level resource heterogeneity by allowing each participant to train a personalized model architecture under a shared training objective. A prevalent paradigm, Partial Training (PT), achieves this by allowing each client to train a subnetwork of the global model. However, existing PT methods typically rely on predefined architectural templates or over-parameterized supernets, limiting fine-grained personalization and imposing substantial computational and memory overhead. We propose FedJigsaw, a novel framework that reshapes model personalization as a dynamic and decentralized model assembly problem. Instead of selecting subnetworks from a predefined supernetwork, each client constructs its model by assembling reusable modules learned from neighboring clients. At the client level, we introduce AttenAssemble to enable each participant to adaptively construct a tailored model based on local observations. To support efficient knowledge sharing under communication and privacy constraints, we design SymbioArchitect, a mechanism that allows clients to exchange granular model modules with their topological neighbors. To mitigate training instability introduced by decentralized module exchange, we design CoRe-Tune, an attention-enhanced centralized training with a decentralized execution strategy, which guides local policies to foster implicit collaboration and stabilize training dynamics, without compromising data privacy. Extensive evaluations demonstrate that FedJigsaw outperforms state-of-the-art MHFL baselines by up to 13.8% in relative accuracy while significantly shrinking cross-client performance variance, but also slashes decision-making latency and peak memory footprint compared to existing policy-driven methods.

## 1. 核心问题与整体含义

- **研究背景**：联邦学习（FL）在真实部署中面临数据、算力和通信异构性。模型异构联邦学习（MHFL）通过让每个客户端训练个性化架构来解决算力异构问题。
- **现有方法的三大瓶颈**：
  - **启发式不灵活**：现有部分训练（PT）方法（如 HeteroFL、FjORD、FlexFL、FedRolex）依赖静态子网络和预定义能力等级，无法为个体客户端定制架构。
  - **资源开销高**：基于知识蒸馏（KD）的方法（如 pFedKnow、FedMRL）需要客户端维护额外的教师/辅助模型，内存和计算开销翻倍。
  - **隐私侵入的集中化**：部分方法（如 FedDF、FedMD）依赖公共数据集进行特征对齐，带来严重隐私泄露和计算负担。
- **理想范式**：每个客户端应能动态、自主地组装定制模型，且架构决策完全去中心化，减少隐私风险和部署成本。
- **核心挑战**：
  - **C1**：低延迟、上下文感知的架构生成（NAS 太贵）。
  - **C2**：异构模型间超越参数层面的结构级知识共享。
  - **C3**：多智能体环境下非平稳性导致的优化不稳定。

## 2. 方法论

### 总体框架：FedJigsaw
- 将 MHFL 中的模型个性化建模为**多智能体协作模型重组问题**，由三大组件构成：`AttenAssemble`、`SymbioArchitect`、`CoRe-Tune`。

### 2.1 AttenAssemble：基于注意力的模型重组
- 将模型构建视为**自底向上的顺序决策过程**（类似拼图）。
- 形式化为 **MDP**：
  - **状态**：已组装模块的元数据序列 + 本地数据特征。
  - **动作**：从候选模块池中挑选维度匹配的模块，或选择 STOP 终止。
  - **转移**：确定性结构转移。
  - **奖励**：稀疏奖励，仅在完整模型评估后获得终止奖励，中间动作使用蒙特卡洛回报（折扣因子 γ）进行信用分配。
- **策略网络**：采用**注意力指针网络（Attention-based Pointer Network）**：
  - 将数据特征、已组装状态 token、候选动作 token 编码为统一序列，送入 Transformer 编码器。
  - 用最后一个已组装层的表示作为 query，与候选模块 key 做点积注意力，得到动作分布。
  - 公式：`πθ(a|s) = Softmax( q W_Q (K_act W_K)^T / (τ √d_model) )`。
  - 使用温度参数 τ 调节探索；用 REINFORCE 算法更新策略。

### 2.2 SymbioArchitect：去中心化模块传播与共享
- 每个客户端保留一个**本地基座模型**作为被动知识库，不参与本地计算。
- 客户端只广播轻量级**结构元数据**（五元组：源客户端 id、层位置、模块类型、输入/输出维度），邻居按需获取物理参数。
- 候选模块池 = 本地基座模块 + 拓扑邻居模块，稳定且不随训练扩张。
- 采用**基于来源的参数聚合**：被借用的模块参数由来源客户端聚合，公式：
  `θ^{j}_{k+1,l} = (1/|P^{j}_{k,l}|) Σ_{p∈P} θ^{j→p}_{k,l}`。
- 同时指出该机制使问题变为 **POMDP** 和非合作博弈，需要额外的协调机制。

### 2.3 CoRe-Tune：注意力增强的 CTDE 调优策略
- 引入**集中训练、去中心化执行（CTDE）** 框架：
  - 服务器端维护一个集中式 Critic，利用全局信息（Transformer 编码后的全局特征、观察历史）估计状态值。
  - 本地 Actor 使用优势函数 `A = r - V_ϑ(h, Z)` 进行策略梯度更新。
- 目标函数：`∇θi J(θi) = E[Σ_t ∇θi log πθi(a_t|h_t) A_ϑ(h_t, Z_t)]`。
- 收敛后服务器可完全解耦，客户端独立决策，同时保留协作行为。
- 该阶段是**可选阶段**：若无可用的代理数据集，可关闭 CoRe-Tune。

  - 系统异构性：轻型 CNN（2/3/4/6 卷积层 + 2 FC 层）用于简单数据集，VGG-11/13/16/19 用于复杂任务。
- **基线方法**：
  - PT 类：HeteroFL、FedRolex、FedShapleX。

## 6. 主要结论与发现

- **性能提升**：FedJigsaw 相对最佳基线平均提升 3.94% 绝对准确率（13.87% 相对提升）；在 High Non-IID 复杂任务（CIFAR-10 84.93%、CIFAR-100 53.77%、Tiny-ImageNet 35.14%）上显著超过现有方法。
- **公平性/稳定性**：跨客户端性能方差显著小于 PT 类方法（如 FEMNIST High Non-IID 上方差仅 0.0431，远低于 FedShapleX 的 0.1877）。
- **效率**：决策延迟 1.11–1.53 秒，比 FedShapleX 快一个数量级；内存占用远低于 pFedHR，且避免了 OOM 崩溃。
- **消融结论**：
  - SymbioArchitect 能有效打破本地数据隔离，提升低 Non-IID 下的准确率。
  - CoRe-Tune 能缓解多智能体非平稳性，显著提升精度和稳定性；即便关闭该模块，FedJigsaw 仍优于多数基线。

## 7. 优点

- **去中心化与隐私友好**：不依赖公共数据集，客户端只需交换轻量元数据，数据分布特征不泄露。
- **架构多样性**：自底向上的模块级组装，摆脱统一超网的拓扑限制，可实现真正的个性化。
- **避免语义错位**：以完整功能模块为组装单位，不破坏残差连接等内部数学结构。
- **高效决策**：指针网络处理动态动作空间，决策延迟低，适合资源受限边缘设备。
- **训练稳定**：CTDE 框架给予全局 Critic 指导，在保隐私前提下实现隐式协作。
- **可扩展性**：相比 pFedHR 等 NAS 方法内存占用和计算成本大幅降低，无 OOM 风险。

## 8. 不足与局限

- **人工指定模块**：依赖人工设计的模块（ResNet Block 等），缺乏自动发现/切分模块的机制。
- **拓扑受限**：仅支持顺序线性的组装，难以生成含跳跃连接或复杂拓扑（如 DenseNet）的架构。
- **被动共享**：模块交换由本地需求驱动，缺少主动的知识扩散机制。
- **安全风险**：去中心化模块交换缺乏集中监管，可能受到 Byzantine 攻击（恶意模块广播）。
- **对辅助数据集的依赖**：CoRe-Tune 需要任务无关的代理数据集，若实际部署中无法获得该数据集，性能会下降（尽管实验显示仍具竞争力）。
- **实验覆盖不足**：仅测试 10 个全连接客户端，未覆盖更大规模、更稀疏拓扑、真实设备异构和通信受限场景；也未与 KD 类方法进行直接对比。
